# AI UI Generator — Describe a UI, Get a Mockup

Describe a UI in words ("a pricing page for a gym") and get a working
HTML/CSS mockup generated by an LLM.

## Features

- Natural-language prompt → generated HTML/Tailwind mockup.
- Live preview in an iframe with a device toggle (desktop/mobile).
- Iterate: "make the header darker" updates the mockup.
- Export the generated code as an `.html` file.

## Standout feature — iterative refinement

You can keep talking to it until the design is right, then export
the code. No re-prompting from scratch.

## Tech stack

- JavaScript + Python, Google Gemini API (free tier), Tailwind CSS,
  iframe preview.
- Offline mode: a template generator builds the mockup from keywords
  in the prompt — no key needed. Set `GEMINI_API_KEY` for real LLM
  generation (key from the environment only, never in code).

## How to run

```bash
python3 src/generator.py --prompt "a pricing page for a gym" --out output.html
python3 src/generator.py --prompt "a pricing page for a gym" --refine "make the header darker" --out output.html
python3 -m pytest tests/ -q
# Web UI: open src/index.html, type a prompt, preview + export in-browser.
```
