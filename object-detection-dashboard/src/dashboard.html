Object Detection Dashboard

Baseline detector, not YOLO. The shipped detector finds solid coloured objects by contour segmentation. The production path is YOLOv8 — see docs/ARCHITECTURE.md.

Run it

pip install -r requirements.txt
python3 src/generate_samples.py
python3 src/detect.py --image assets/samples/rack_scene.png --out assets/detections/

Annotated images + JSON results land in assets/detections/; every run appends to detection_log.csv.

Count by zone

python3 src/detect.py --image assets/samples/rack_scene.png --zone 10,10,200,150 counts only objects whose centre falls inside that rectangle.

Confidence control

--min-area is the baseline's confidence control: raise it to ignore small specks, lower it to catch small objects. In YOLOv8 this becomes a real --conf threshold.
