# Usage — Virtual Showroom (3D)

Open `src/index.html` in a browser (Three.js via CDN).

- Click a glowing ring (hotspot) to move to that product.
- Click a product box for its detail panel + price, then **Add to
  shortlist** — the shortlist (bottom-left) collects products as you
  browse, with a running total in INR.
- **Day/night toggle** re-lights the room: warm daylight vs. dim
  evening with the lamps as the main light.
- Edit products in `assets/products.json`.
