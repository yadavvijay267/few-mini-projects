# Screenshots

Place screenshots of the running project in this folder and reference them
from the README.

Suggested captures:
- `desktop.png` — the main view on a desktop-width browser window.
- `mobile.png` — the main view at a phone width (around 390px).
- `feature.png` — the project's standout feature in action.

To capture one: open `src/index.html` in a browser, use the app, then take a
screenshot (or use the browser's DevTools device toolbar for the mobile shot).
