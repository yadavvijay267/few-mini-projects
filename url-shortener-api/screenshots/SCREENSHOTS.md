# Screenshots

Add screenshots of the project in this folder and reference them from the
README. Suggested captures:

- `api-demo.png` — a terminal session showing the server starting and a
  successful curl request/response.
- `dashboard.png` — the demo client or dashboard in a browser (if any).
- `tests.png` — the test suite passing (`npm test` output).

Keep images under ~1 MB each and prefer PNG.
