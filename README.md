## ▶️ How to use

1. Pick a project folder above and open its own `README.md`.
2. Follow its setup steps (usually `npm install` / `pip install -r requirements.txt`).
3. Run it and try it out — samples are in the [Samples ZIP](./Few-mini-projects-samples.zip).
