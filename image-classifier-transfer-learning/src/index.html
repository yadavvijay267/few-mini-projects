Honesty note

The shipped model is a LogisticRegression baseline on hand-built features — it is not a frozen MobileNetV2 backbone. The transfer-learning production path is documented in docs/ARCHITECTURE.md.

What it reports

Top-3 predictions with confidence, test accuracy, per-class precision/recall, confusion matrix and a learning curve — all in models/metrics.json.
